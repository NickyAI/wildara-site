# Production audit · Wildara Africa Safaris

Branch: `production-hardening` · audited and fixed 22 Nov 2026 · target: `https://wildaraafricasafaris.com` on Hostinger.
Companion documents: `DEPLOYMENT.md`, `SEO_AUDIT.md`, `RESPONSIVE_QA.md`.

## Architecture (from the code, not assumed)

| Aspect | Finding |
|---|---|
| Framework | None. Hand-written HTML/CSS/vanilla JS. **Not React or Next.js**; no `package.json`, no bundler. |
| Generation | Python static-site generator (`tools/build.py`) expands templates in `tools/src/` and data (`safaris.json`, `content-*.js`) into `Site/`. |
| Rendering | **SSG** (pre-rendered HTML per URL) + progressive enhancement in JS (animations, maps, filters, sliders). |
| Routing | Folder-per-route static files (`/safaris/<slug>/index.html`). No client-side router, so no SPA fallback is needed or used. |
| Backend / DB / auth / APIs | None. Forms post JSON to an optional third-party endpoint (`WILDARA_CONFIG.formEndpoint`), currently unset. |
| UI stack | Custom CSS design system (brand tokens), no UI library, no animation library. |
| State | Local, per-page vanilla JS; URL query string for listing filters. |
| Deployment | Static files on Hostinger (LiteSpeed + `.htaccess`). |

## Issues found and fixed

| P | Problem | Root cause | Fix | Verification |
|---|---|---|---|---|
| P1 | 55 detail pages shared one URL template; identical title/description/no canonical in raw HTML | Client-rendered `?id=` pages | Build generates real pages with unique metadata, JSON-LD and pre-rendered content | `seo.py` 0 errors; JS-disabled render contains itinerary + FAQs |
| P1 | No sitemap, robots.txt, canonical, 404 page | Never created | Generated by build; custom 404 with real status | `smoke.py`, `seo.py`, curl |
| P1 | No server config: directory listings, `.htaccess`/hidden files exposure, 404 handling, HTTPS, www | No config existed | `tools/htaccess` → `Site/.htaccess` (`-Indexes`, ErrorDocument, hidden-file block, HTTPS, www→apex, legacy 301s) | `serve.py` mirrors it; `/assets/` 404 (no "Index of"), `/.htaccess` 404 |
| P1 | Itinerary filter dropdowns cut off on phones; itinerary content clipped at 320–360 px | Non-wrapping flex row; grid item `min-width:auto` | Wrap + shrink rules | `responsive.py` 0/195 problems |
| P1 | Runtime JS overwrote unique descriptions with generic copy (duplicates ×5) and injected a second Article JSON-LD | Leftover client-side `setMeta` / LD injection | Removed; HTML is the single source of metadata | `smoke.py` duplicate check 0 |
| P2 | Hero images lazy-loaded despite `fetchpriority="high"` | Helper emitted `loading="lazy"` first; duplicates keep the first | Eager for priority images; never duplicate the attribute | 0 duplicates site-wide |
| P2 | Homepage LCP 8.3 s (lab, 4G) | Headline hidden until all JS loaded | CSS-only hero entrance; dropped unused data scripts from home | 1.06 s |
| P2 | Detail LCP 4.6–5.8 s, itinerary CLS 0.152 | Hero photo and facts panel injected by JS; no mid-size image; late font swap | Pre-rendered heroes/facts, `<link rel=preload>` heroes, new 960 px WebP size, self-hosted preloaded fonts | LCP 1.8–2.7 s, CLS 0.000 everywhere |
| P2 | Inline scripts prevented a strict CSP | Boot logic inline in `<head>` | Moved to `assets/js/boot.js`; CSP `script-src 'self'` | 0 CSP violations in Chrome/WebKit/Firefox |
| P2 | Accessibility: planner H1 hidden from screen readers, nested landmarks, heading skips, duplicate form labels, footer `h4` after `h2` | Markup | Fixed templates | axe 0 violations (15 pages × 2 viewports) |
| P2 | Gallery alt text "Safari photograph 3"; JS images without dimensions | Generic placeholder | 34 descriptive alts; width/height on all generated images | `interactions.py` |
| P2 | Third-party font requests (Google Fonts) | External CSS + woff2 | Self-hosted 3 woff2 files (63 KB, OFL); privacy policy updated | fonts load in all 3 engines |
| P2 | Forms had no spam protection; contact form allowed double submits | Missing | Honeypot field on both forms; submit lock | `interactions.py` |
| P3 | Long titles (76–115 chars) | Template | `fit_title()` ≤ 65 chars | `seo.py` 0 warnings |
| P3 | No cache strategy | — | Hash-versioned CSS/JS (1-year immutable), fonts 1 year, media 30 days, HTML no-cache | headers verified with curl |

## Security

| Check | Result |
|---|---|
| Secrets / credentials in repo or bundles | none found; there are no secrets in this project |
| XSS | all data-to-HTML paths escape via `esc()` (JS) / `html.escape` (build); no `eval`, no `innerHTML` of user input |
| Headers | CSP (`script-src 'self'`, no third-party origins), HSTS, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy |
| Exposure | hidden files blocked; `tools/` and sources are not uploaded; no directory listings |
| Forms | client validation + honeypot; **server-side validation/spam filtering is the responsibility of the chosen form service** |
| Residual | `style-src 'unsafe-inline'` is needed for inline `style` attributes (low risk without script injection). |
